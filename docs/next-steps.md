## 앱 만들기 2단계: 안드로이드 플레이스토어 (TWA)
1. 패키지 이름 확정 → 앱 껍데기(AAB) 설정, 업로드용 서명 키 생성 (Play 앱 서명 사용)
2. 사이트에 /.well-known/assetlinks.json (앱 ↔ 사이트 연결)
3. 카카오 콘솔에 안드로이드 플랫폼 추가 (패키지 이름 · 키 해시)
4. 스토어 등록 자료: 짧은 설명, 자세한 설명, 스크린샷, 대표 그림 1024×500, 연령 등급 설문, 개인정보 처리방침 주소
5. 내부 테스트 트랙으로 먼저 올려 친구들과 확인
